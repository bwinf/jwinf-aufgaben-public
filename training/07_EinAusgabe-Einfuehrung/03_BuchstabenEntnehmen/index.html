Schreibe ein Programm:

Das Programm soll eine Textzeile einlesen und den 1. Buchstaben ausgeben.

Du kannst in python auf ein Zeichen einer Zeichenkette zugreifen, indem du eckige Klammern [ ] benutzt. Wir beginnen dabei immer bei 0 mit dem Zählen. Um auf das erste Zeichen zuzugreifen schreiben wir also: text[0].

Weitere Hinweise:

Mit dem Baustein kann aus einem Text ein Buchstabe an folgenden Positionen entnommen werden:
  • nimm: der Buchstabe wird an einer bestimmten Position entnommen.
  • nimm von hinten: der Buchstabe wird an einer bestimmten Position von hinten gezählt entnommen.
  • nimm ersten: der erste Buchstabe wird entnommen.
  • nimm letzten: der letzten Buchstabe wird entnommen.
  • nimm zufälligen: ein zufälliger Buchstabe wird entnommen.

Über den kleinen Pfeil, können dir verschiedenen Optionen ausgewählt werden.

Hinweis: Die Variable Text im Baustein kann auch durch ersetzt werden.

Das Programm soll eine Textzeile einlesen und das 4. Zeichen von hinten wieder ausgeben.

In python können wir nicht nur vorne anfangen zu zählen, sondern auch hinten. Wir beginnen dabei immer bei -1 mit dem Zählen. Um auf das letzte Zeichen zuzugreifen schreiben wir also: text[-1].

Das Programm soll die Wörter einlesen und abwechselnd den ersten und letzten Buchstaben ausgeben.

Hinweis: Es steht immer eine gerade Anzahl Wörter in der Eingabe.
