Program the robot:

The robot must take each fish and drop it on an island .

The number on the signs indicates:

  • for each island how many fishes have to be delivered.
  • for each net how many fishes can be taken from this net.

Hint: The robot can carry only one fish at a time.

For further instructions please check SHOW DETAILS.

Details:

You can formulate a condition with an if. You can use this to execute a command only under certain conditions. For example, if you use:

The robot only picks up a fish if it is standing on a field with a fish.

The robot cannot drop a fish if he is not carrying one.

Using the block you can check if the robot is on a field with a fish.

Using the block you can check if the robot is on a field with an island.

The robot does not have a sensor to check, wether he is carrying a fish or not. Every row has exactly one island and one fish.
